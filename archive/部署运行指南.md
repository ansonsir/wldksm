# ScanScript v3.0 部署运行指南

## 一、环境要求

- Python 3.8+
- Linux 系统（Kali/Ubuntu/CentOS 等）
- rustscan 可执行文件（已包含在项目根目录）

## 二、安装依赖

在项目根目录执行：

```bash
cd /home/yinsongkai/Desktop/杨其顶-work/Code-yang/ScanScript
pip install -r requirements.txt
```

依赖列表：
- Flask >= 2.0.0
- flask-cors >= 4.0.0
- docxtpl >= 0.16.0
- python-docx >= 0.8.11
- PyYAML >= 6.0

## 三、初始化数据库

首次运行前需初始化数据库：

```bash
python cli.py --init-db
```

此命令会创建 SQLite 数据库并填充默认数据（扫描区域、端口信息、邮件设置等）。

## 四、运行方式

### 方式一：Web可视化界面（推荐）

```bash
python web_server.py
```

默认启动在 `http://0.0.0.0:5000`

指定端口：
```bash
python web_server.py --port 8080
```

启用调试模式：
```bash
python web_server.py --debug
```

用浏览器访问即可使用图形化界面进行扫描配置、任务管理、报告下载和邮件发送。

### 方式二：命令行模式

```bash
# 普通区域扫描（指定端口）
python cli.py

# 红区扫描（全端口 1-65535）
python cli.py --mode redarea

# 指定配置文件
python cli.py --config data/config.yaml

# 查看扫描历史
python cli.py --history

# 查看统计信息
python cli.py --stats
```

## 五、配置说明

### 5.1 扫描配置

编辑 `data/config.yaml`：

```yaml
# 文件路径配置
ip_range_file: "scan_configs/ip_ranges/default.txt"
exclude_ips_file: "scan_configs/excludes/default.txt"
ports_file: "scan_configs/ports/default.txt"

# 扫描参数
max_workers: 32        # 并发线程数
ulimit: 32768          # 文件描述符限制
timeout: 300           # 单网段超时（秒）
```

### 5.2 IP范围配置

编辑 `scan_configs/ip_ranges/default.txt`，每行一个CIDR格式网段：

```
# 普通区域IP范围
10.0.0.0/24
192.168.1.0/24
```

### 5.3 端口配置

编辑 `scan_configs/ports/default.txt`，每行一个端口：

```
21
22
80
443
3389
3306
```

### 5.4 邮件配置（可选）

**方法一：配置文件**

编辑 `data/config.yaml`：

```yaml
smtp_server: "smtp.example.com"
smtp_port: 587
smtp_user: "your_email@example.com"
smtp_password: "your_password"
smtp_ssl: true
default_sender: "scanner@example.com"
default_recipients: "admin@example.com, boss@example.com"
```

**方法二：Web界面配置**

访问 Web 界面 -> 系统配置 -> 邮件配置，填写 SMTP 信息后保存并测试连接。

## 六、使用Web界面发送报告邮件

1. 完成一次扫描后，进入"报告管理"页面
2. 找到目标报告，点击"发送邮件"按钮
3. 在弹窗中填写：
   - 收件人（支持多邮箱，用逗号分隔）
   - 邮件主题（可选，默认自动生成）
   - 邮件正文（可选）
4. 点击"发送"按钮

若已在配置中设置默认收件人，弹窗会自动填充。

## 八、常见问题

**Q: 启动Web服务后无法访问？**
A: 检查防火墙是否放行对应端口，或尝试指定 `127.0.0.1` 本地访问。

**Q: 邮件发送失败？**
A: 确认 SMTP 服务器地址、端口、账号密码正确，部分邮箱需要开启 SMTP 授权码。

**Q: rustscan 命令找不到？**
A: 确保项目根目录下的 `rustscan` 二进制文件有执行权限：
```bash
chmod +x rustscan
```

**Q: 如何修改报告模板？**
A: 在 Web 界面的"模板管理"页面上传新的 `.docx` 模板文件，或使用命令行：
```bash
python cli.py --template-add /path/to/template.docx 模板名称
```
